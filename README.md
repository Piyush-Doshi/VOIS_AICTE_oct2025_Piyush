# 📊 Data Analysis Projects – Airbnb & Netflix

This repository contains two end-to-end data analysis projects completed as part of the **VOIS AICTE Internship (Oct 2025)**.  
The projects focus on extracting insights from real-world datasets using Python and data visualization tools.

---

## 📁 Projects Included

### 1️⃣ Airbnb Data Analysis
📌 File: `Airbnb_Analysis.ipynb`

#### 🔍 Objective
To analyze Airbnb listings data and uncover patterns in pricing, availability, and location trends.

#### 📊 Key Insights
- Price distribution across different locations
- Relationship between room types and pricing
- Availability trends throughout the year
- Most popular neighborhoods

#### 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

### 2️⃣ Netflix Data Analysis
📌 File: `Netflix_analysis.ipynb`

#### 🔍 Objective
To explore Netflix dataset and identify trends in content type, genre, and release patterns.

#### 📊 Key Insights
- Distribution of Movies vs TV Shows
- Most common genres on Netflix
- Content growth over the years
- Country-wise content production

#### 🛠️ Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
